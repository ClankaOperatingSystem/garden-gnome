# The garden doctrine

Standards for a garden: the Org files that hold a tree of
responsibilities, projects and tasks. The doctrine covers the voice of
the prose in those files and the structure of the tree.

The files in this directory are joined in filename order into one
document. A model judging a policy is given that document, then the
policy's instructions. A person reads it as the standard that every
finding cites.

Each clause has an id, and a finding cites the id of the clause it was
raised under. An id is never reused, so the numbers have a gap where a
clause was retired.

A policy's header lists the clauses it judges. A clause no policy lists
is guidance, and no finding is raised under it.

A garden's files are judged as standing text, not as a change. A passage
is reported as it is found, whether or not the change under review added
it.
